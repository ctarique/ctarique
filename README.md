## Selected Work

### Sentinel-CPS

Zero-trust edge gateway architecture for securing remote CPS/IoT education labs.

Sentinel-CPS combines a hardened Raspberry Pi gateway, ESP32-based autonomous edge nodes, isolated physical execution, telemetry monitoring, and AI-assisted anomaly detection. The project is designed around the problem of safely exposing physical cyber-physical systems to remote or semi-trusted users without giving direct access to the underlying hardware environment.

**Core areas:** CPS/IoT security, zero trust, Linux edge gateways, telemetry, anomaly detection
**Stack:** Raspberry Pi, ESP32, Flask, nftables, Ed25519 access control, eBPF observability, Python, C/C++

---

### OrbitSec

High-assurance cryptographic bridge for resource-constrained embedded systems.

OrbitSec implements an Encrypt-then-Sign / Verify-then-Decrypt workflow using a Python uplink and C firmware decoder. The project includes ECDSA P-256 signature validation, AES-256-CBC encryption, STRIDE threat modeling, and fuzz testing for malformed packet handling.

**Core areas:** embedded security, applied cryptography, secure packet validation, threat modeling, defensive firmware design
**Stack:** C, Python, AES-256-CBC, ECDSA P-256, STRIDE, fuzz testing

---

### Eramba CE GRC Lab

This work uses Eramba CE to model risk registers, control documentation, vulnerability evaluation workflows, and audit-readiness practices. Public materials are being sanitized to preserve confidentiality while still demonstrating practical GRC implementation, documentation quality, and security governance thinking.

**Core areas:** GRC, risk assessment, control documentation, audit readiness, security governance
**Tools and concepts:** Eramba CE, NIST 800-30, NIST CSF, risk registers, policy/control mapping, technical documentation
