Featured Public Projects

Sentinel-CPS

Zero-trust CPS/IoT gateway and simulator for remote cyber-physical systems education labs.

Sentinel-CPS is my master’s thesis project. It explores how a hardened edge gateway can protect physical CPS/IoT lab equipment from remote or semi-trusted users while still allowing controlled experimentation, telemetry collection, and security monitoring.

The project combines a Raspberry Pi gateway, ESP32-based autonomous edge nodes, isolated physical execution, encrypted wireless communication, telemetry monitoring, and AI-assisted anomaly detection. A browser-based simulator supports the project by demonstrating the system architecture, protocol behavior, and telemetry flow before full hardware execution.

Core areas: CPS/IoT security, zero trust, secure remote labs, Linux edge gateways, telemetry, anomaly detection
Stack: Raspberry Pi, ESP32, Flask, Python, C/C++, nftables, Ed25519 access control, ESP-NOW, eBPF observability

OrbitSec

High-assurance cryptographic bridge for resource-constrained embedded systems.

OrbitSec implements an Encrypt-then-Sign / Verify-then-Decrypt workflow using a Python uplink and C firmware decoder. The project includes ECDSA P-256 signature validation, AES-256-CBC encryption, STRIDE threat modeling, and fuzz testing for malformed packet handling.

Core areas: embedded security, applied cryptography, secure packet validation, threat modeling, defensive firmware design
Stack: C, Python, AES-256-CBC, ECDSA P-256, STRIDE, fuzz testing
